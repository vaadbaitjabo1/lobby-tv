# Lobby TV — NOTES.md

## מה זה
מסך לובי לבניין ז'בוטינסקי 1, אזור (76 דירות).
מוצג על 2 טלוויזיות חכמות בלובי.

## סטאק
- React + Vite + Tailwind
- Supabase (פרויקט: lobby-tv)
- GitHub Pages לפרסום

## עיצוב
Light Luxury — רקע שמנת/לבן, אלמנטים זהב כהה ואנתרציט.
CSS variables מרוכזים בקובץ אחד לשינוי קל.

## מסכים (מחזור אוטומטי)
1. מסך ראשי (רוב הזמן)
2. דשבורד פיננסי (iframe)
3. עסקים מומלצים

## מסך ראשי — אזורים
- שעה + תאריך עברי/לועזי + יום
- מזג אוויר (OpenWeatherMap, עיר: אזור)
- גלריית תמונות/סרטון מתחלף
- הודעות לדיירים
- טיקר חדשות ynet (RSS, מתעדכן כל שעה)
- widget שבת (שישי/שבת בלבד) — זמני כניסה + פרשה + מוסר השכל
- מפורסמים יום הולדת
- QR code — פתיחת תקלה לחברת הניהול
- דגל ישראל מתנוסס בפינה עליונה

## מוזיקה
YouTube Premium embed — פלייליסט מנוהל מהפאנל

## Supabase Tables
- announcements — הודעות לדיירים
- gallery — תמונות/סרטונים
- businesses — עסקים מומלצים (~20)
- playlist — פלייליסט YouTube
- settings — הגדרות כלליות

## פאנל ניהול /admin
- מוגן בסיסמה
- preview לפני פרסום
- ניהול כל הטבלאות
